# EMSUB — IJIEOM submission preparation

This directory contains the three-stage editorial workflow and the source-audit/placement records for *The Decision Architecture of Supply Chain Management*. The complete newest-source LaTeX bundle and rendered PDFs have also been generated as a downloadable conversation ZIP; they are **not yet committed as GitHub binary/source files**, so this folder does not claim a complete online manuscript upload.

The latest uploaded `main(2).zip` and `BlindM.zip` supersede the older repository `paper/main.tex` skeleton. Nothing in the original research source was deleted. The separate conversation package contains: blinded main, separate tables, anonymised supplement, non-blind title page, untouched author originals, figures and audit reports.

IJIEOM rules verified from https://www.emeraldgrouppublishing.com/journal/ijieom : 9,000 words including 250 words per figure/table; structured four-part abstract; Harvard references; double anonymous; LaTeX plus PDF acceptable; tables separate; supplementary content permitted. Emerald's publication ethics rules still apply.

The journal-facing main text is deliberately qualified: the primary SCDA9 selection is not a universal model-depth result, and core coding-agreement and temporal holdout issues remain unresolved.
