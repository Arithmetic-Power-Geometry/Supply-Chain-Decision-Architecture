# Comparator Stress Test — v1

## Purpose
Test SCDA against the strongest multidimensional literature classifications rather than one-dimensional controls.

## Representations
SCDA nested models:
- K4 = decision level + process + flow + objective
- KS7 = K4 + theory + method + technology
- KSV8 = KS7 + evidence maturity
- SCDA9 = KSV8 + industry/context

Comparator families reconstructed from original sources include:
- decision level + optimization topic + objective + optimization model;
- information + context + modelling approach + supply-chain decision;
- supply-chain process + strategic/tactical/operational level + analytics/method family;
- sector-specific hierarchical decision taxonomies.

## Primary tests
For the same coded study set:
1. codability/coverage;
2. collision rate;
3. signature entropy;
4. information gain per added dimension;
5. leave-one-dimension-out ablation;
6. inter-coder reliability by dimension;
7. era and discipline robustness;
8. interpretable separation cases.

## Evidence-maturity test
Evidence maturity is a candidate differentiator, not an assumed contribution.

Matched-case analysis will identify studies that share a comparable decision/problem representation but differ in evidence maturity, for example conceptual proposal versus simulation, benchmark, pilot, deployed, or longitudinal evidence.

The test asks whether retaining that distinction changes interpretation of what the literature actually demonstrates.

## Decision rule
Prefer the smallest representation that preserves substantively useful distinctions with acceptable coding reliability. If evidence maturity, theory, flow, technology, or context adds negligible or unreliable information, remove or demote it.

## Claim gate
No statement that SCDA is more informative, comprehensive, parsimonious, or useful than prior frameworks is permitted until this stress test is run on the frozen real corpus.
