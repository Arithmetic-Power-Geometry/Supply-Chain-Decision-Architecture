# Stage-2 Full-Text Eligibility Protocol v1

Stage 2 begins only from records included at Reviewer-A Stage 1. The expected entry queue is 659 records after the Stage-1 finalizer passes.

Each record receives one terminal full-text decision: include, exclude, or uncertain during adjudication. Exclusions use the frozen E01-E10 code system and require a note when the code alone is insufficient.

Full-text status is recorded separately from eligibility. A record is not excluded merely because automated retrieval fails. Publisher/DOI pages, legitimate repository copies, and other documented scholarly sources may be used for verification. Inaccessible evidence is coded according to the protocol rather than silently discarded.

Primary studies and explicit review/synthesis papers remain separately routed. Review papers support prior-framework and synthesis analysis; they are not mixed with primary-study claim-level evidence unless the analysis explicitly requires that layer.

Reviewer-A decisions remain AI-assisted and do not substitute for independent second coding. The G4 reliability sample is selected independently and remains a hard downstream gate.

Stage 2 is frozen only after every Stage-1 inclusion has a terminal eligibility decision, all exclusions have valid reasons, all uncertainties are adjudicated, and the final eligible corpus has unique stable IDs.
