# Primary Study Pilot v1

## Purpose
This pilot is a calibration and falsification exercise, not the final systematic corpus.

Eight verified landmark primary studies spanning 1997–2020 are provisionally coded using the frozen SCDA codebook.

## Rules
- Blank theory means no theory is assigned without explicit source support.
- "Probable" codes are not publication-grade evidence.
- Multi-objective studies receive a conservative primary objective for pilot testing only.
- Process mappings that depend on interpretation must be checked against full text before production use.
- Pilot records cannot support prevalence estimates.

## Questions
1. Can the Decision Kernel be coded consistently across eras?
2. Does separating technology from evidence maturity prevent misleading equivalence?
3. Which dimensions repeatedly require interpretive judgment?
4. Does K4 already distinguish most pilot records?
5. Which candidate matched cases differ mainly in solution/evidence layers?

## Gate
No pilot metric is a headline result. The pilot is used to revise coding guidance only when ambiguity is genuine and documented.
