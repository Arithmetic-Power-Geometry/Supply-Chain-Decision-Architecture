# SCDA paper assembly map v1

Status: pre-results manuscript architecture. This file contains no provisional empirical findings.

## Writing trigger
The complete journal paper is written after the following artifacts are frozen:
1. admissible production claim corpus and SHA-256 digest;
2. pre-reliability adjudication closure;
3. final blinded publication-clustered >=20% Coder-B sample;
4. genuine Coder-B return and pre-adjudication reliability;
5. any reliability-triggered codebook action and sensitivity specification;
6. K4 -> KS7 -> KSV8 -> SCDA9 comparison;
7. ablation, parsimony, temporal/disciplinary holdouts, evidence/context matched cases, bootstrap, robustness, and managerial-usefulness artifacts.

## Artifact-to-paper rules
- 705-candidate and 659-screening artifacts -> Methods/review-flow only.
- 141 excluded studies -> screening provenance only.
- 176 review/framework studies -> historical synthesis, review-of-reviews, closest-framework reconstruction, and legitimately cited background.
- admissible claims from retained primary studies -> empirical architecture analyses.
- reliability artifacts -> Reliability section only after genuine Coder-B return.
- frozen architecture/robustness outputs -> Results, figures, tables, Discussion, Abstract and Conclusion.
- repository/software artifacts document reproducibility; they are not described as having generated or written the paper.
- bibliography contains every and only sources actually cited in the paper.

## Consistency gate
Abstract, Results, Discussion, Managerial Relevance Statement and Conclusion must report the same frozen empirical story and numbers. No provisional number is inserted into the paper.
