# Final SCM

Publication-facing evidence package for the SCDA manuscript.

This folder is synchronized to the final paper's reported analytical results. Superseded development-stage 55/70 workbooks are not part of this final-facing set.

## Contents
- SCDA_125_Frozen_Model_Competition_Ablation_FINAL.xlsx — frozen model-competition workbook.
- model_competition_primary_FINAL.csv — K4/KS7/KSV8/SCDA9 primary comparison.
- nested_sensitivity_FINAL.csv — tolerance/penalty sensitivity.
- scda9_ablation_FINAL.csv — leave-one-dimension-out ablation.
- generalization_summary_FINAL.csv — publication/disciplinary/generalization checks.
- bootstrap_summary_500_FINAL.csv — 500-replicate study-cluster bootstrap.
- managerial_decision_usefulness_FINAL.csv — managerial ambiguity diagnostics.
- Cohen_Kappa_125_FINAL.csv — full 125-study dimension-wise inter-coder agreement.
- coder_architecture_sensitivity_FINAL.csv — coder-specific architecture collision diagnostics.
- repeated_holdout_500_FINAL.csv — repeated 80/20 record-level holdout selection frequencies.
- permutation_null_5000_FINAL.csv — permutation-null diagnostic reported in the manuscript.

Coder B is the independent human second coder. Cohen's kappa is reported dimension-wise; no single global kappa is claimed.
