# G20 Adversarial Reviewer and Submission-Readiness Gate v1

## Purpose
G20 asks whether the evidence package is strong enough to authorize construction of the final submission manuscript. It is not an acceptance prediction or journal score.

## States
PASS: the registered evidence artifact exists and its own validation reports pass.
BLOCKED: an artifact exists and reports a failing condition, or is unreadable.
NOT-YET-EVALUABLE: required empirical evidence has not yet been generated/frozen, or the artifact does not expose a recognized validation state.

The overall state is BLOCKED if any required gate is blocked. Otherwise it is NOT-YET-EVALUABLE while any required gate remains pending. Only when all required gates pass is paper construction authorized.

## Adversarial review
The reviewer matrix represents objections that could invalidate or materially narrow the paper: architecture necessity, mechanical dimensional advantage, genuine framework comparison, independent reliability, holdout generalization, V/I necessity, systematic corpus construction, sparse-cell gap claims, managerial relevance, artifact reproducibility, citation support, cross-section claim consistency, double blindness, manuscript mechanics and sensitivity to analytic choices.

A response to an objection must point to evidence, not rhetoric.

## After PASS
A G20 PASS authorizes the new manuscript to be written from the frozen evidence package. It does not guarantee publication. After writing, manuscript-specific G13--G20 checks are rerun against the final source and PDF; failures return the package to correction.

## Current-development interpretation
During infrastructure construction, NOT-YET-EVALUABLE is expected and scientifically preferable to fabricated pass results.
