# SCDA Coding Codebook

Each study receives one primary code per field for the principal analysis. Secondary codes may be stored separately when genuinely multi-label.

## Decision level
Strategic: long-horizon structural choices.
Tactical: medium-horizon resource/planning choices.
Operational: routine execution decisions.
Real-time/autonomous: event-driven or machine-speed decisions.

## Process
Plan, Source, Make, Store, Move, Deliver, Return, Recover, Enable.

## Flow
Material, Information, Financial, Knowledge, Risk, Carbon.

## Objective
Cost, Service, Quality, Speed, Flexibility, Resilience, Sustainability, Trust.

## Theory
Record the explicit theoretical lens when declared. Do not infer a management theory merely from topic.

## Method
Conceptual, Empirical, Optimization, Simulation, Statistics, Machine Learning, Artificial Intelligence, Multi-agent/Autonomous.

## Technology
Record the principal enabling technology, or None when the contribution is not technology-dependent.

## Evidence maturity
Conceptual: argument/framework without empirical test.
Synthetic: constructed numerical examples.
Simulation: simulation-generated evaluation.
Benchmark: recognized or reproducible benchmark/data evaluation.
Case study: bounded organizational/industry case.
Observational: real-world observational data.
Pilot: limited operational trial.
Deployed: operational implementation evidence.
Longitudinal: real-world evidence observed across time.

## Industry
Use the reported application context. Code General when no industry is central.

## Uncertainty
Every code should support: certain / probable / ambiguous. Ambiguous records enter sensitivity analysis and are not silently forced into a category.
