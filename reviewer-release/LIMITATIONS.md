# Methodological limitations and verification status

1. **Intercoder agreement:** Cohen's kappa ranges from 0.036 to 0.712; eight of nine dimensions fall below the protocol's 0.67 internal development threshold. Retention for exploratory architecture comparison departs from the protocol's revise/merge/demote/remove gate.
2. **Provenance:** The reported 125-pair agreement statistics were numerically recomputed from a supplied paired workbook. Independent historical coding, pre-adjudication timing, and the original handoff chronology have not been independently authenticated.
3. **Units and missingness:** The main architecture experiment uses 124 analytical claims; the paired coder test uses 125 study records. The latter treats blank theory ratings as a category; the original claim-level reliability script drops missing pairs. These procedures are not interchangeable.
4. **Temporal generalisation:** The prespecified 2024–2026 temporal holdout contains zero qualifying analytical records. It provides no temporal validation.
5. **Model selection:** SCDA9 has the lowest observed full-corpus collision under the stated rule, but preferred representation depth varies with tolerance, coder and sampling. Added fields can reduce collision mechanically, as the permutation diagnostic illustrates.
6. **Evidence availability:** The original paired-coder workbook and several source workbooks are not confirmed to be present in the GitHub evidence deposit. Existing summaries are not a substitute for original files.
7. **Claims:** These findings concern within-corpus classification and representation; they do not establish a stable observer-independent taxonomy, improved organisational performance, or external predictive validity.
