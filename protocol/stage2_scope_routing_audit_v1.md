# Stage-2 Scope and Routing Audit v1

This audit protects the final corpus from broad-query contamination and primary/review routing errors.

The automated audit is deliberately non-destructive. It flags records for semantic review; it never converts a Stage-1 inclusion into a Stage-2 exclusion. Flags include absence of an explicit SCM/logistics/operations signal, broad-domain titles, and provenance from the broad technology query O004.

Every flagged record must be evaluated against the frozen eligibility criteria using the strongest accessible scholarly evidence. A flag is not evidence of ineligibility.

Review/synthesis records are also checked for routing. A paper is routed as review only when it is an explicit literature review, synthesis, bibliometric review, or prior-framework comparison. Original empirical, analytical, conceptual, Delphi, case-study, method, theory-building, or newly proposed/tested framework studies remain primary unless the source establishes otherwise.

All corrections are recorded by stable record ID with source support. The audit must be resolved before the Stage-2 corpus is scientifically frozen.
