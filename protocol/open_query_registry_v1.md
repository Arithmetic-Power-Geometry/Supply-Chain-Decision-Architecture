# Frozen Open-Evidence Query Registry v1

The four query families are complementary rather than interchangeable. O001 emphasizes precision around the field label; O002 protects recall; O003 targets decision/process vocabulary; O004 targets solution-method and enabling-technology vocabulary.

The registry is frozen before inspecting SCDA large-corpus performance. Query changes after retrieval must create a new registry version and be justified from retrieval-quality diagnostics, not from whether they improve SCDA results.

The date boundary is 2026-10-01. Search-family membership is retained through deduplication so overlap is measurable. Retrieval counts are reported as database/index results, not as eligible-study counts.

OpenAlex is an open-index discovery source. Crossref and publisher metadata are verification layers. The study must not describe this corpus as Scopus or Web of Science evidence unless those databases are actually executed.
